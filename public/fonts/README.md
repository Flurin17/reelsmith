# Fonts

Put licensed font files here and reference them in `reelsmith.config.ts`:

```ts
fonts: {
  display: { family: 'Brand Display', source: 'local', src: 'fonts/BrandDisplay-Bold.woff2', weights: ['700'] },
  body: { family: 'Inter', weights: ['500', '700'] }, // Google Fonts by family name
},
```
