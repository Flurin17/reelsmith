# Music

Drop licensed tracks here (`.mp3`/`.wav`) and reference them in a job:
`"music": { "file": "track.mp3", "volume": 0.3 }`.

This folder is git-ignored except for this README — most music licenses do not
allow redistribution. Keep narration audible: 0.08–0.15 under voiceover, up to
0.5 for music-only videos.
