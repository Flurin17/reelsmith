# Contributing

Thanks for helping! A few conventions keep Reelsmith usable by both humans and agents.

## Setup

```bash
pnpm install
pnpm typecheck && pnpm test
REELSMITH_RENDER_TESTS=1 pnpm test   # also renders + reviews the example jobs (slower)
```

## Guidelines

- **Templates** are one file in `src/templates/<Id>/`, built from `src/theme/primitives`
  and `useTheme()` only, animate from the frame number, keep text inside `SAFE`, ship an
  example job, and pass `pnpm reelsmith review` with at least two brands.
- **Brands** are `brands/<id>/` (theme.ts, guidelines.md, catalog) and must pass
  `pnpm reelsmith brand <id>`.
- **CLI commands** are non-interactive, print file paths, and fail with an actionable
  message. If you add or rename a command, update `skills/` (a test checks that every
  command mentioned in a skill exists).
- **Skills** follow the SKILL.md format (`name` = folder name, description ≤ 1024
  chars), stay agent-agnostic (shell commands and files, not one agent's tool names)
  and short — agents pay for every line.
- **Assets**: only commit media you can redistribute under the MIT license (SFX are generated by `pnpm reelsmith sfx`; demo products are hand-made SVGs).
- Keep tests deterministic (no network, no clocks). Rendering tests live in
  `tests/*.render.test.ts` and are skipped unless enabled.
