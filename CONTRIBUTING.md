# Contributing

Thanks for helping! A few conventions keep Reelsmith usable by both humans and agents.

## Setup

```bash
pnpm install
pnpm typecheck && pnpm test
REELSMITH_RENDER_TESTS=1 pnpm test   # also renders + reviews the example jobs (slower)
```

## Guidelines

- **Templates** must read every color/font from `useBrand()`, animate from the frame
  number only, keep text inside `SAFE`, ship an example job in `examples/jobs/`, and
  pass `pnpm reelsmith review` with no errors. Prefer a genuinely different visual
  language over a variation of an existing template.
- **CLI commands** are non-interactive, print file paths, and fail with an actionable
  message. If you add or rename a command, update `skills/` (a test checks that every
  command mentioned in a skill exists).
- **Skills** follow the Agent Skills format (`name` = folder name, description ≤ 1024
  chars) and stay agent-agnostic: reference shell commands and files, not one
  agent's tool names.
- **Assets**: only commit media you can redistribute under the MIT license (the SFX are
  generated by `pnpm reelsmith sfx`; demo products are hand-made SVGs).
- Keep tests deterministic (no network, no clocks). Rendering tests live in
  `tests/*.render.test.ts` and are skipped unless enabled.
