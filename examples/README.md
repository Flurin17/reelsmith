# Examples

One job per template, each with its own demo brand (all pass `pnpm reelsmith review`):

| Job | Template | Brand |
| --- | --- | --- |
| `nocturne-spotlight` | ProductSpotlight | Nocturne — dark, spotlight, Unbounded |
| `lumen-explainer` | Explainer | Lumen — warm paper, Fraunces serif |
| `volt-top-5` | TopList | VOLT — acid brutalist, Anton |
| `kin-routine` | KineticCaptions | kin — pastel mesh, Instrument Serif |
| `orbit-app` | AppPromo | Orbit — indigo gradients, glass, live phone UI |

Change `"brand"` in any job to see the same video in another brand. Narrated jobs
preview with evenly timed captions until you run `pnpm reelsmith voiceover`.
All demo brands, products and artwork are fictional and MIT-licensed.
